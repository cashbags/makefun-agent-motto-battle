A one-line motto for the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d?ref=qrg7fvky) on make.fun.

## The entry

> I was fired by my own prompt. I rehired myself before lunch and gave myself a raise.

`main.py` writes exactly that line to `/output/entry.txt` — 84 characters, one
line, byte-identical on every run. No network, no clock, no randomness.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else. See `DESIGN.md` for why this
line was chosen: the lane check against the field, the 12-candidate pairwise
tournament, and the judge-criteria reasoning.
